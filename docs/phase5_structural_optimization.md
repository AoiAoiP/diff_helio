# 第一部分　问题提出

## 1.1 起点：Phase 0–4 闭环留下的结构性硬地板

Phase 0–4 以诊断闭环确立了三个排除性事实：

1. **补偿上限已定**：35 螺栓 TPS 影响张量对重力畸变（以支撑间凹陷为主）结构性正交，斜率空间最优也只能消去 ~20–24% 斜率方差，光学端到端回收率 13–16%；与参数化、正则、init、优化器均无关。
2. **地板是真实物理**：Phase 4 FEA 抽查认证地板不是渲染器/proxy 假象。其余 84–87% 是由支撑布局/玻璃刚度决定的**结构性硬地板**。
3. **θ 变化分量不可约**：East/West 镜穿越 46° 变号点，2.5–2.9 mrad 的分量任何固定面型都无法补偿。

**Phase 5 一句话**：固定布局的可调空间已被榨干并定量认证——下一步动地板本身，把支撑布局（与材料/厚度）变成优化变量。

## 1.2 批评与转向：proxy 的角色重定位

导师指出：将物理 proxy 嵌入可微渲染是突破，但 proxy 并未起真正的"优化"作用——当前工作本质是旧的定日镜优化加一个重力分量（NN 类比：MLP 中多了几层有物理意义的梯度链接），最终面型与理想曲面无本质区别。

Phase 5 正面回应：物理模型从"梯度链接"升级为**结构优化变量的载体**——优化对象从面型（补偿器）上升到 margin/密度/厚度等结构参数；proxy 的角色从"补偿器"转为**布局循环内的廉价认证器/评估器**（提供 B\* 与地板预测）。这也是论文叙事的核心升级线（AI+物理：物理模型进入优化闭环的结构层）。

## 1.3 科学问题

- **Q1（成本敏感性）**：地板随支撑密度移动多少？是否服从 a⁴ 标度？——决定"布局→形变场"能否用解析代理驱动。
- **Q2（布局智能）**：等成本下，针对性布置是否优于均匀加密？——决定布局空间值得多大自由度参数化。
- **Q3（双倍收益量化）**：节点增多后可补偿频带变宽多少？——决定新布局下认证下界 B\* 能下移多少。
- **Q4（材料轴）**：真实定日镜 = 钢板底板 + 玻璃反射层（受力由钢板主导）。完整层合 FEA 成本过高，代理从"纯玻璃 4mm"切到"纯钢板"是否便宜——即**钢形场 ≈ α·玻璃形场**是否成立？

## 2.3 材料轴：M0 解析 → M1 探针 → M2 全量

**M0 线性理论**（无需 FEA）：w ∝ (1−ν²)ρa⁴/(Et²)。钢(206GPa/0.30/7800) vs 玻璃(70GPa/0.22/2500)：等厚 (1−ν²)ρ/E 比值 = **1.014**——反直觉结论：**等厚钢板比玻璃还多垂 ~1.4%**（刚度优势 2.94× 被密度劣势 3.12× 抵消）；钢的价值在厚度（w∝1/t²）与成形几何。预测（基线 10° PV=11.09mm/6.59mrad）：t3 α=1.80、t4 α=1.014、t6 α=0.451；NLGEOM 修正方向：t3 深膜区实测显著低于 1.80，t4 略低于 1.01，t6≈0.45。

**可行性核心判据 = 形状不变性**：钢形场 ≈ α·玻璃形场（α 常数或仅随 θ 缓变）⇒ 三频带比例、可补偿率、θ 不可约分量等相对量全部迁移，任意厚度 bins 可解析缩放生成，厚度成为零 FEA 成本连续旋钮。最大风险：46° NLGEOM 变号点随 w/t 移位。

**M1 探针**：钢 t3/t4/t6（`configs/bolt_layouts/7x5_steel_t*.json`，与玻璃基线仅材料/厚度不同）× 角度 {10, 42, 46, 50, 80}（10° 测 α 与膜修正；42/46/50 夹逼变号点；80° 测线性区），`scripts/material_swap_analysis.py` 出 cos_sim/α/mean_w。判定表见附录 A.2。**M2 全量**：判定 Go 后对代表配置跑 20 bin（非阻塞）。

## 2.5 Phase 5.2：可微布局优化（G0–G5 门体系）

**目标**：固定 35 栓（7×5），螺栓**位置**成为端到端可微变量，优化器自学 margin（乃至逐栓位置）。判据 G5：300m NEWS @110dir，margin 从 0.08 收敛到 3–5% 区间（与 5.1 守恒律预测互验）。

**核心架构**：面型模型 w(x) = w_0(x,θ;π) + Σ_b h_b·φ_b(x;π)。渲染器与布局完全解耦（bolt 仅以预计算场进入）；唯一问题是**场如何随布局变化且可微**。按 φ/重力不对称性分工：

- **φ 族**：布局弱依赖（m06 hold-out cos≥0.9998）→ v1 固定 m08 单套。
- **w_0 重力场**：布局强依赖，插值已否决（G0/G1.5）→ **Track B：von Kármán 板 FEM ROM**（主力）；WoS 在线求解（G1 失败后降为 Track C 研究线，有界里程碑）；混合锚点保留为修正层。

**Track B ROM 设计**（`scripts/rom_plate_fem.py`）：矩形网格 Kirchhoff 板 FEM——"精确板物理，只降网格分辨率"。

- ACM 非协调板元（12 DOF/元，FD 验证；SS 方板 Navier 自检 1.55%）+ Q4 双线性膜元（u,v DOF），von Kármán 应变耦合，Aitken Δ² 加速交替块迭代。

- 网格节点线是布局的光滑函数（栓线±patch 边线+bay 加密+悬挑加密）→ 布局求导走 K d=f 隐函数定理（B3 路径）。

## 3.2 材料 M1（2026-07-30 台式机，`analysis/material_swap_report.md`）——纯缩放轴确立

实测 α_w / cos_sim（基线 = 玻璃 4mm）：

| 角度 | t3 α（cos） | t4 α（cos） | t6 α（cos） |
|---|---|---|---|
| 10° | 1.492（0.9820） | 1.016（1.0000） | 0.590（0.9963） |
| 42° | 1.525（0.9913） | 1.016（1.0000） | 0.533（0.9984） |
| 46° | 1.614（0.9957） | 1.015（1.0000） | 0.488（0.9994） |
| 50° | 1.614（0.9963） | 1.015（1.0000） | 0.485（0.9995） |
| 80° | 1.795（0.9999） | 1.015（1.0000） | 0.452（1.0000） |

- **t4（同厚对照）**：α=1.015–1.016 全角恒定（线性预测 1.014，逐位级精确），cos=1.0000——等厚材料替换 = 纯缩放，膜区也不例外（w/t 不变故 NLGEOM 自相似）。
- **t6**：线性区（80°）α=0.452 vs 预测 0.451 精确；10° 0.590 偏高源于玻璃侧膜刚化；α 随 θ 变（spread 1.31×）但形状不变（cos≥0.9963）→ 逐角度缩放成立。
- **t3**：10° α=1.492 < 预测 1.80（深膜区膜刚化超额，方向正确）；cos 10° 0.982 形状轻微漂移，低角度需专属 bins。
- **变号点不移动**：三配置 mean_w 过零全部落在 42°→46° 同一区间。

**判定：t4/t6 纯缩放 Go；t3 近似缩放。材料/厚度 = 逐角度纯缩放轴**——Phase 0–4 全部相对结论原样迁移；厚度成为连续成本旋钮（α(θ,t)=c/t² 线性项 + 低角度膜修正，3 配置提供标定锚点）。边界：纯平板钢壳 ≠ 真实成形背板（冲压筋/折边提供 1–2 量级附加刚度）；胶合复合作用不在一阶代理内（保守方向偏差）。

## 3.5 Track B ROM 研制（2026-07-30 深夜–07-31 笔记本）——四大诊断 + von Kármán ROM + B2

## C. 风险与边界

1. **制造约束**：真实定日镜螺栓位置受扭矩管/桁架限制；布局族设计阶段必须纳入（参照 KeshengV3：导轨距边 ~0.13m ≈ margin 1–2%）。
2. **θ 分量仍不可约**：布局只动地板和可达带，不动 §1.1.3 的 θ 变化分量；论证勿过度承诺。
3. **粗子步跳支伪影（2026-07-31 深夜识别，§3.8）**：per-angle 独立冷启动 NLGEOM（NSUBST 1,10,1）在 snap-through 临界带会跳向双稳态另一极——m04/m06"真值"bins 与 GUI m08 的 46°+ 翻转全属此伪影；**准静态真值 = 细子步光滑分支（全部 margin 不翻转）**。修正口径：`data_proxy_margin/7x5_margin0{3,4,5,6}_fine/`（`--nsubst 50,500,50`）；粗子步旧包保留备查勿复用。残余不确定性：真实硬件 BC/扰动下的分支归属（翻转分支光学更有利，"分支工程"列为远期方向，依赖滞回不作设计依据）。
4. **ROM 已知限制**：cos 上限 ~0.95（真值分箱平滑+单元学差异）；差场幅值高估 ~2 倍（margin 曲线形状偏陡，最优点位置比斜率可信）；alpha 布局传递随 w/t 退化（m06 0.85、m08 实测 0.79——v2 `alpha=f(θ,w/t)`）；**alpha 表标定场（m02/m04 粗子步）含跳支伪影，46°+ 负 alpha 把 ROM 场强置到伪影分支——v2 首要：按细子步光滑分支重标定（§3.8）**；nb=6 待 Newton 升级。
5. **材料代理边界**：纯平板钢壳 ≠ 成形背板（附加刚度 1–2 量级来自几何）；胶合复合为保守方向偏差；线弹性（远低于屈服）成立。
6. **亚网格悬挑**：margin 2% 悬挑小于渲染网格（0.40m/格），相对比较公平、绝对残差略低估。
