## 1. Introduction（~850 词）

**定位**：开篇立"物理耦合可微渲染"这一新问题，交代为什么 CSP 定日镜是理想试验场。

**核心主张（claims）**：
1. 可微渲染已成熟（Mitsuba2/ZeroGrads/glints-diff），但共享一个隐含前提——反射面是固定的，梯度止于表面交点参数 [16,17,18]。
2. 一旦表面是物理载荷（重力）的函数，梯度必须穿越结构力学域——这是图形学传统视为"外部"的域。
3. 定日镜是理想试验场：重力弯沉 2.3–8.5 mrad，与 Buie 日轮（~2.2 mrad, CSR=0.01）同量级 [15,26]；CSP 已有多篇可微光追先例 [1,2,3,4,5]，但它们只动刚体自由度（瞄准/canting）或做逆问题计量，从不回答"表面该被设计成什么样"。
4. 工程侧离线"FEA+光追"串行枚举存在（[21–25]），但无梯度、无法回答"物理上限在哪里"。

**研究问题**：RQ1 惩罚多大 / RQ2 物理上能补多少 / RQ3 如何操作（保留底稿 §1.1 三问，措辞微调）。

**贡献（4 条）**：
1. 物理耦合可微渲染框架（→§4）
2. 梯度可达性界限分析（→§5）
3. 由界限驱动的结构层重设计（→§6.4）
4. 设计规则与"优化器边界 vs 物理边界"可分性范式（→§7）

**证据映射**：贡献 1→§4；2→§5+§6.3；3→§6.4（margin −26.7%）；4→§7.1。

**图表**：无（或 1 张框架总览小图，可选）。
