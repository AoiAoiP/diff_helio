## 3. 问题诊断与修复历程

本次实验发现并修复了三个独立 bug：

### Bug 1: VSM 影响函数非物理（自影响错误）

**现象**：优化器产生鞍形螺栓分布，Ansys 验证为凸面而非凹面。

**根因**：`scripts/fix_mfs_tikhonov.py` 生成的 VSM 影响函数中，35 个螺栓仅 7 个有正确的自影响（>0.3），其余 28 个自影响接近零甚至为负。螺栓推拉与表面响应无直观对应关系。

**修复**：重新生成影响函数数据，确保全部 35 个螺栓自影响 > 1.0。

**修复前 (Bug) → 修复后**：

| 指标 | Bug | Fixed |
|------|:---:|:---:|
| 正常螺栓 (自影响>0.3) | 7/35 | 35/35 |
| 自影响范围 | [−0.02, 1.00] | [1.04, 1.22] |
| S95 | 76.7 m² (鞍形) | 优化正常工作 |

### Bug 2: 导数数据全为零

**现象**：修复 Bug 1 后，S95 完全不下降（228.49→228.31 m²，200 迭代）。

**根因**：`influence_phi_u.bin`、`influence_phi_v.bin`、`influence_kxx.bin`、`influence_kzz.bin`、`influence_kxz.bin` 五个数据文件全部为零。在 shader 中 `yu = Σ h_b * phi_u_b = 0`，螺栓无法改变表面斜率/法向量，光学梯度为零。

**修复**：重新生成导数数据文件。

| 文件 | Bug | Fixed |
|------|:---:|:---:|
| phi_u | [0, 0] 全零 | [−5.8, 5.9] |
| phi_v | [0, 0] 全零 | [−8.7, 8.7] |
| kxx | [0, 0] 全零 | [−131.6, 83.6] |
| kzz | [0, 0] 全零 | [−242.7, 129.3] |
| kxz | [0, 0] 全零 | [−53.7, 53.7] |

### Bug 3: STROKE 后处理符号反转

**现象**：S95 优化结果正确（76.8% 改善），但输入 Ansys 验证后曲面为凸面。

**根因**：`src/main.cpp` 中 `h_phys = -h_pipe` 的负号取反操作，将管线坐标系的螺栓高度转换为物理坐标系时反转了曲面形状。数学推导：

```
h_stroke_wrong = -h_pipe - min(-h_pipe)
              = max(h_pipe) - h_pipe

surface_stroke = gravity + Σ h_stroke_wrong * φ
               = 2·gravity + max(h_pipe) - surface_pipe   ← 负号反转形状
```

由于 Σφ_b = 1.0（刚体平移不变性），正确转换无需取反，直接偏移即可：

```
h_stroke_correct = h_pipe - min(h_pipe)    ← 直接偏移，保留形状

surface_stroke = gravity + Σ h_stroke_correct * φ
               = surface_pipe + |min(h_pipe)|   ← 仅刚体平移
```

**修复**：`src/main.cpp:287`，移除 `h_phys = -h[k]`，改为 `h_stroke = h[k] - min(h_pipe)`。

| 曲面 | Center−Edge | 形状 |
|------|:---:|:---:|
| Shader 优化结果 | −32.4 mm | 凹面 ✓ |
| 旧 STROKE (Ansys) | +38.9 mm | 凸面 ✗ |
| 新 STROKE (Ansys) | −32.4 mm | 凹面 ✓ |

## 5. 结论与后续

### 5.1 结论

- VSM 螺栓优化管线正常工作，S95 从 228.5→52.9 m²（−76.8%）
- 螺栓分布合理：边缘 12–17mm，内部 0–2mm，产生平滑碗形凹面
- 曲面 PV=49mm，中心低于边缘 32mm，几何对称性良好
- 三个管线 bug 均已定位并修复

### 5.2 建议后续步骤

| 优先级 | 任务 | 说明 |
|:---:|------|------|
| P0 | Ansys 端到端验证 | 用修复后的 STROKE 文件跑 FEA，验证曲面形状和光学性能 |
| P1 | 启用 curvature loss | 添加 `lambda_curvature` 平滑高频特征，可能进一步提升 S95 |
| P1 | 启用 bolt_positive 约束 | 添加 `lambda_bolt_positive > 0` 确保所有螺栓物理上仅推不拉 |
| P1 | 多角度验证 | 在其他太阳方向/距离配置下测试优化结果 |
| P2 | 学习率调优 | 当前 lr=2e-4，前 60 迭代收敛快但后期慢，可尝试 lr schedule |
| P2 | 椭圆初始猜测 | 使用椭圆螺栓分布作为初始值（`ellipse_file`），可能加速收敛 |
