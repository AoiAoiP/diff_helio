# Phase 5.4 方案：自由螺栓布局的端到端可微优化

> **状态**：方案设计（2026-08-03）。前置：Phase 5.2 ROM 驱动 margin 扫描完成（m\*≈0.04–0.05）。
> **本文档为 Phase 5 远期扩展方案**。

---

## 1. 动机：从 margin 扫描到逐栓自由布局

Phase 5.2 用 ROM 驱动的外环扫描确定了最优 margin≈4–5%，但把螺栓位置**限制在均匀矩形网格内**（仅 margin 一个自由度）。两个未解决的问题：

1. **均匀性是否最优？** 悬挑带承载 80–90% 的斜率能量——如果把螺栓集中在边缘、中心稀疏，是否能以更少的螺栓达到相同的 S95？
2. **非对称镜位是否需要专用布局？** East/West 镜全年穿越 46° NLGEOM 变号点，倾角分布不对称——x 向和 z 向的最优螺栓间距可能不同。

颜健等人 [21] 的离线参数扫描发现"螺栓数 N≥11 后改善可忽略"——这个结论建立在**均匀间距**的前提下。如果螺栓可以自由放置，N 的递减回报是否取决于*位置*而非*数量*？我们的假设是：

> **位置 >> 数量**。少量螺栓放在悬挑带边缘 + 少量放在中心，可能比大量均匀分布的螺栓更有效。

---

## 2. 三条技术路径

### 路径 A：B3 — 逐栓位置的隐函数梯度（保守）

**原理**：ROM 求解 $K(\pi)d = f(\pi)$，对布局 $\pi$ 求导走隐函数定理：

$$\frac{\partial d}{\partial \pi_{ij}} = K^{-1}\left(\frac{\partial f}{\partial \pi_{ij}} - \frac{\partial K}{\partial \pi_{ij}} d\right)$$

然后链式传播到 $w_0$ → 表面梯度 → S95。每个螺栓有 2 个坐标（$x_b, z_b$），$N_b=35$ 共 70 维。

**前提条件**：
- ROM 网格升级 nb=4→6，提高 G3 差场精度（当前 128×96 细网格裁决未做）
- Aitken 迭代 → Newton 切线法（需要 $K^{-1}$ 或高效线性求解器）
- G4 验证：FD vs 解析梯度一致性
- G3 重新裁决：需要细网格 ANSYS 128×96 真值参考

**风险**：均匀矩形网格 + 凸优化 → 可能直接收敛到均匀网格（信息量为零）。物理太光滑了。

### 路径 B：稀疏自由布局（推荐）

**原理**：从过密初始网格（如 11×9=99 栓）出发，在 S95 损失中加**螺栓"存在性"惩罚**（Group LASSO 或 L1），让优化器自动淘汰不必要的螺栓：

$$\min_{h, \pi} \text{S95} + \lambda \sum_{b=1}^{N_b} w_b \cdot \| (h_b, x_b - x_b^{(0)}, z_b - z_b^{(0)}) \|_2$$

其中 $w_b$ 是 Group LASSO 权重。当一个螺栓组的范数被压到零以下，该螺栓被移除。Adam + 近端梯度（proximal gradient）交替。

**期望行为**：
- 边缘螺栓被保留（悬挑带 80–90% 能量）
- 中心螺栓被优先淘汰（内部凹陷能量仅 10–20%）
- **如果 35 栓 → 25 栓（淘汰 10 个中心螺栓）后 S95 几乎不变 → 证明了"位置 >> 数量"**

**与颜健组的直接对话**：颜健组说"N≥11（≈5×3 网格，每排 5 栓）后改善可忽略"——但他们的结论建立在均匀间距上。稀疏优化可能给出一个**非均匀的 25 栓布局**，其 S95 优于 35 栓均匀布局。这将直接修正颜健组的结论：不是"N 不重要"，而是"均匀布 N 不重要；非均匀布 N 可以少而精"。

| | 颜健组 [21,22] | 本方案 |
|---|---|---|
| 螺栓位置 | 均匀间距 | **自由** |
| 优化方法 | FEA 参数扫描 | ROM 梯度 + Group LASSO |
| 评估指标 | 斜率误差 RMS | 年均 S95 |
| 核心结论 | N≥11 改善可忽略 | 预测：N 不重要，位置重要 |

**风险**：Group LASSO 的 λ 调度需要调参；近端梯度 + ROM 的反向传播链需要验证梯度正确性。

### 路径 C：子镜式分面优化（远期，独立课题）

**原理**：将 12.84×9.45m 单板拆为 $M \times N$ 块子镜（如 2×2=4 块），每块独立布螺栓 + canting。直接消灭跨距问题。

**风险**：全新的 ANSYS 建模 + 渲染器多面板支持 + 子镜间 canting 优化。保守 4-6 周，**建议作为独立第二篇论文**。

## 3. 推荐路径 B 的 G0–G5 门体系

| 门 | 内容 | 判据 |
|:---:|------|------|
| G0 | ROM 梯度正确性 (FD vs 解析, 单栓位置) | 相对差 <10% |
| G1 | 小扰动布局验证（1 栓位移 0.1m, ROM 预测 vs ANSYS 真值） | cos > 0.90 |
| G2 | Group LASSO 稀疏路径正确性（已知最优解的人工噪声实验） | 能恢复已知最优解的支撑集 |
| G3 | 35→稀疏优化：自由布局 vs 均匀 7×5 的 S95 比较 | S95 不变或改善，螺栓数显著减少 |
| G4 | 对颜健组 N 递减回报的修正验证 | 证明非均匀少栓可达均匀多栓的 S95 |
| G5 | 300m NEWS @110dir 端到端，给出最优非均匀布局 | 边际增益 + 螺栓数减少的证据 |

## 4. 预期产出与叙事定位

### 如果成功（稀疏布局确实好于均匀）

> "颜健等人发现 N≥11 后均匀加密的回报可忽略——我们证明这不是'N 不重要'，而是'位置比数量重要'。让优化器自由选择螺栓位置 + 稀疏正则化，可以用 25 个螺栓达到 35 个均匀螺栓的 S95。悬挑带需要密集支撑，中心可以稀疏——这个设计规则是参数扫描无法发现的。"

### 如果失败（自由布局 ≈ 均匀布局）

> "我们尝试了逐栓位置优化 + 稀疏正则化，但优化器自发收敛到近似均匀的矩形网格。这反向证明了 Phase 5.1 的 margin-密度守恒律是全局的——对于均匀各向同性板，均匀网格确实是全局最优。'让螺栓自由'的直觉被严格证伪。"

**两种结果均可发表**——这就是门体系的价值。
