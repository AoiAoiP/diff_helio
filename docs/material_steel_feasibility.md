# 材料替换可行性分析：纯玻璃 → 纯钢板 FEA 代理

> **背景**：真实定日镜反射模块 ≈ 钢板底板 + 玻璃反射层，受力行为由钢板主导。
> 完整层合 FEA 成本过高，拟将代理模型从"纯玻璃 4mm"切换为"纯钢板"。
> **本文档回答**：(1) 换材料的理论预期是什么；(2) 用什么最小实验验证
> "换材料 = 纯缩放"这一可行性前提；(3) 台式机怎么跑、怎么判定。
>
> 与布局扫描（`docs/phase5_layout_optimization.md`）相互独立，可并行跑；
> 两者共用同一条 `gravity-ansys` 管线，零代码改动。

## 1. 线性理论预测（M0，无需 FEA）

薄板自重挠度：w ∝ q·a⁴/D，q=ρgt，D=Et³/12(1−ν²)，故

**w ∝ (1−ν²)·ρ·a⁴ / (E·t²)**

材料参数：玻璃 E=70 GPa, ν=0.22, ρ=2500；结构钢 E=206 GPa, ν=0.30, ρ=7800
（取自 KeshengV3 参考工程 Structural Steel，见 `analysis/kesheng_v3_parameters.md`）。

(1−ν²)ρ/E 比值 钢/玻璃 = (0.91×7800/206e9)/(0.9516×2500/70e9) = **1.014**。

> **反直觉结论：等厚度下钢板下垂比玻璃还多 ~1.4%**——钢 2.94× 的刚度优势被
> 3.12× 的密度劣势基本抵消。钢的价值不在"材料"而在**厚度**（w∝1/t²）
> 与成形几何（见 §5 风险）。

各候选配置的线性预测（基线 = 玻璃 4mm，10° 实测 PV=11.09mm、斜率 RMS=6.59mrad）：

| 配置 | t (mm) | 面密度 (kg/m²) | α_pred | 10° PV 预测 (mm) | 10° 斜率预测 (mrad) |
|---|---|---|---|---|---|
| 玻璃基线 | 4.0 | 10.0 | 1.000 | 11.09 | 6.59 |
| 钢 t3 | 3.0 | 23.4 | 1.802 | ~20.0 | ~11.9 |
| 钢 t4（对照） | 4.0 | 31.2 | 1.014 | ~11.2 | ~6.7 |
| 钢 t6 | 6.0 | 46.8 | 0.451 | ~5.0 | ~3.0 |

参考点：等挠度厚度 t_iso = 4×√1.014 ≈ **4.03mm**；等弯曲刚度厚度 t≈2.75mm
（此时 α≈2.14，因面密度翻倍反而更软——"按刚度等效"是错误映射，勿用）。

**NLGEOM 修正方向**（10° 为膜效应区，玻璃 PV 已达 2.8× 厚度）：

- t3：w/t≈6.7，膜刚化更强 → 实测 α **显著低于** 1.80；
- t4：w/t≈2.8，与玻璃相当 → 实测 α 略低于 1.01；
- t6：w/t≈0.83，接近线性 → 实测 α ≈ 0.45。

这组带方向的预测即 M1 的可证伪检验点：实测 α 若全部落在预测方向上，
说明物理理解正确，α(t) 可用"线性项 + 膜修正"标定。

## 2. 可行性的核心判据：形状不变性

我们整条管线消费的是 `gravity_{θ}deg.bin` 形场。材料替换是否"便宜"，取决于：

> **钢形场 ≈ α·玻璃形场**（α 为常数或仅随 θ 缓变）是否成立？

- 三频带比例、TPS 可补偿率（R²、20–24% 斜率方差）、θ 不可约分量的**相对值**
  全部是尺度不变量——形状不变则 Phase 0–4 结论**原样迁移**，只需把地板幅度
  乘 α；任何厚度的 bins 可由基线**解析缩放**生成，厚度成为零 FEA 成本的
  连续成本旋钮（α(t)≈c/t² + 膜修正），与布局轴组合成二维成本前沿。
- **最大风险是 46° NLGEOM 变号点位置随 w/t 移动**。t3（深膜区）最可能移位；
  变号角若移动超过一个 bin 间距（4°），§1.1.3 的 θ 分布结论需按新材料修订，
  且该区间 bins 需加密。

## 3. 实验设计

### M0　解析预测 —— 本文档 §1，已完成。

### M1　探针（判决性，15 次 ANSYS 运行，预计 1.5–2 h）

- 配置：钢 t3 / t4 / t6（JSON 已在 `configs/bolt_layouts/7x5_steel_t*.json`，
  布局、网格、边界条件与玻璃基线逐一致，仅材料/厚度不同）；
- 角度：**10, 42, 46, 50, 80**——10° 测 α 与膜修正；42/46/50 夹逼变号点；80° 测线性区。
- 测量项（`scripts/material_swap_analysis.py` 自动算）：
  - `cos_sim`：形场余弦相似度（形状不变性判据）；
  - `alpha_w` / `alpha_slp`：实测缩放 vs §1 预测；
  - `mean_w` 符号：变号点追踪（基线 42° 为 −0.203mm，46° 附近过零）。

### M2　全量（M1 通过后）

选定代表配置跑默认 20 bin，重算 §1.1 全套分解与 S95 惩罚表（乘 α 即可，
FEA 仅用于验证缩放精度），产出"真实材料版"论文数字。

### 判定标准（§4.4 也印在分析报告尾部）

| 结果 | 判定 | 后续 |
|---|---|---|
| 全部角度 cos_sim ≥ 0.99 | **纯缩放（Go）** | 任意厚度解析缩放；α(t) 三点标定；Phase 0-4 结论迁移 |
| 0.95 ≤ cos_sim < 0.99 | 近似缩放 | 高角度可缩放，低角度（膜区）需材质专属 bins |
| cos_sim < 0.95 | 形状漂移 | 全量重跑 + 重做 §1.1 分解；本身是物理发现（膜/弯比随材质变） |
| 变号角移位 > 4° | 附加风险 | 42–50° 区间 bins 加密，§1.1.3 按新材料修订 |

## 4. 台式机执行手册

仓库根目录（`L:\Code\bezier_opt_desktop`）。与 110dir 复核、布局扫描均不冲突
（ANSYS/CPU vs GPU），license 紧张时排队即可。

**Step 1　M1 探针**：

```bash
for t in t3mm t4mm t6mm; do
  python scripts/generate_proxy_model.py gravity-ansys \
    --bolt-layout configs/bolt_layouts/7x5_steel_${t}.json \
    --output-dir data_proxy_steel/${t} \
    --angles 10 42 46 50 80
done
```

**Step 2　分析**（纯 numpy，无需 license）：

```bash
python scripts/material_swap_analysis.py \
  --baseline data_proxy \
  --scan steel_t3=data_proxy_steel/t3mm \
  --scan steel_t4=data_proxy_steel/t4mm \
  --scan steel_t6=data_proxy_steel/t6mm \
  --output analysis/material_swap_report.md
```

把 `analysis/material_swap_report.md` 发回即可判定。

**Step 3　M2 全量**（判定 Go 后）：对选定配置去掉 `--angles` 重跑（默认 20 bin）。

注意：

- 若报 `build/` 不存在：`mkdir build`。
- `data_proxy_steel/` 已加入 .gitignore——只有报告回来。
- t3 在 10° 深膜区（w/t≈7）可能收敛变慢；若某角度失败，先记录失败事实发回，
  不要自行改 NSUBST——那是结论的一部分（深膜区需要更细载荷步）。

## 5. 风险与边界

- **纯平板钢壳 ≠ 真实成形背板**：真实产品靠冲压筋/折边获得 1–2 个数量级的
  附加刚度。若真实背板是 ~1mm 成形薄板，纯平板代理在该厚度下 α≈16，明显失真
  ——说明真实刚度来自几何而非材料。代表厚度应通过实物实测或详细模块 FEA 标定，
  M1 的三点 bracket 正是为标定提供锚点。
- **胶合复合作用不在一阶代理内**：钢+玻璃键合复合会进一步抬刚度（变换截面法），
  属保守方向的偏差（代理高估挠度），作为模型的保守下界可接受。
- **线弹性假设**：SHELL181 + NLGEOM，无塑性；最大应力水平远低于屈服，成立。
- **布局扫描的基线选择**：若 M1 判 Go，布局扫描结论同样可按 α 缩放迁移到钢材；
  不必用钢材重跑布局扫描，除非 cos_sim 在 0.95–0.99 区间（那时布局扫描的低角度
  bin 需要材质专属数据）。
