# Phase 5　支撑布局优化：移动结构性地板

> **前置结论**（`docs/gravity_compensation_experiment.md`）：重力修复后成为光学主导项，
> 35 螺栓面型调节对其畸变的补偿上限仅 ~13–16%；其余 84–87% 是支撑布局/玻璃刚度决定的
> **结构性硬地板**（Phase 4 FEA 已认证为真实物理），与参数化、正则、init、优化器均无关。
>
> **Phase 5 一句话**：固定布局的可调空间已被榨干并定量认证——下一步动地板本身。
> 用"布局变更 → 地板移动"的可微/代理化框架，把支撑布局变成优化变量。

---

## 1. 动机：为什么布局是唯一的剩余杠杆

诊断闭环后，三个事实排除了除结构外的一切杠杆：

1. **补偿上限已定**：35 螺栓 TPS 张量对重力畸变（以支撑间凹陷为主）结构性正交，
   斜率空间最优也只能消去 ~20–24% 的斜率方差（主报告 §1.1.2）。
2. **地板是真实物理**：Phase 4 FEA 抽查确认地板不是渲染器/proxy 假象。
3. **θ 变化分量不可约**：East/West 镜穿越 46° 变号点，2.5–2.9 mrad 的分量
   任何固定面型都无法补偿（§1.1.3）。

同时布局变更带来**双倍收益**，这是它比"换玻璃"更有研究价值的原因：

- **地板下移**：凹陷 ∝ 支撑跨距⁴（板理论 w≈qa⁴/384D），加密支撑直接压缩高阶频带；
- **可达性上升**：TPS 节点数增加 → 可补偿频带变宽 → 原本够不着的均值场分量变得可补偿。
  地板与天花板同时相向移动。

---

## 2. 科学问题

Phase 5 按顺序回答三个问题：

- **Q1（成本敏感性）**：地板随支撑密度移动多少？是否服从 a⁴ 标度？
  ——决定"布局→形变场"能否用解析代理驱动。
- **Q2（布局智能）**：等成本下，针对性布置是否优于均匀加密？
  ——决定布局空间值得用多大自由度参数化。
- **Q3（双倍收益量化）**：节点增多后，可补偿频带实际变宽多少？
  ——决定新布局下认证下界（B\*）能下移多少。

Phase 5.0（本文档 §3 的扫描实验）只需回答 Q1+Q2，是后续一切投入的判决性前置实验。
Q3 不需要 ANSYS（TPS 影响函数是纯数学），扫描通过后用
`generate_proxy_model.py tps --bolt-layout <json>` 生成各布局影响函数、
对既有重力场做投影分析即可。

## 3. Phase 5.0　判决性扫描：三个候选布局

### 3.1 设计依据与布局定义

基线 7×5（35 螺栓，margin 8%）的支撑跨距：

- Δx = 12.84 × 0.84 / 6 = **1.798 m**
- Δz = 9.45 × 0.84 / 4 = **1.985 m**　← z 向（沿倾斜方向）跨距更大，是结构弱方向

三个候选（同一板/玻璃/边界条件，只动螺栓数量与位置，margin 均保持 8%）：

| 布局 | JSON | 螺栓 | Δx (m) | Δz (m) | 设计意图 |
|---|---|---|---|---|---|
| **L1** 8×6 | `configs/bolt_layouts/8x6_dense.json` | 48 (+37%) | 1.541 | 1.588 | 均匀加密，两向均衡 |
| **L2** 7×7 | `configs/bolt_layouts/7x7_zdense.json` | 49 (+40%) | 1.798 | 1.323 | 只切弱方向 z（等成本对照） |
| **L3** 9×7 | `configs/bolt_layouts/9x7_dense.json` | 63 (+80%) | 1.348 | 1.323 | 激进加密，探地板渐近线 |

**L1 vs L2 是扫描的核心对照**：两者成本几乎相同（48 vs 49），但 L1 均匀切两向、
L2 只切 z 向。而两个候选标度模型对它们的相对优劣给出了**相反**的预测（§3.2），
因此这一对照对代理模型选型具有判决性。

### 3.2 先验预测（10° 最坏工况，凹陷分量比值）

| 布局 | max-span⁴ 模型 | Navier 简支板模型 |
|---|---|---|
| 基线 7×5 | 1.00 | 1.00 |
| L1 8×6 | **0.41** | 0.47 |
| L2 7×7 | **0.67** | 0.41 |
| L3 9×7 | 0.21 | 0.25 |

- max-span⁴：w ∝ (最大跨距)⁴ —— 点支撑"枕头模态"的朴素估计；
- Navier：w ∝ (1/Δx² + 1/Δz²)⁻² —— 四边简支矩形板基频估计；
- 真实结构（角点点支撑）介于两者之间，**实测落点决定 surrogate 用哪个函数族**。
- 10° 时高阶凹陷占斜率 RMS 的 96.5%（6.36/6.59），故凹陷比 ≈ 总斜率比。

### 3.3 台式机执行手册

在台式机仓库根目录（`L:\Code\bezier_opt_desktop`）执行。与 110dir 复核不冲突
（110dir 用 GPU + 既有 bins，本扫描用 ANSYS/CPU），可并行；若抢 ANSYS license 则排队。

**Step 1　快速探针**（4 角度 × 3 布局 = 12 次 ANSYS 运行，预计 <1.5 h）：

```bash
for lay in 8x6_dense 7x7_zdense 9x7_dense; do
  python scripts/generate_proxy_model.py gravity-ansys \
    --bolt-layout configs/bolt_layouts/${lay}.json \
    --output-dir data_proxy_scan/${lay} \
    --angles 10 30 58 80
done
```

**Step 2　探针分析**（纯 numpy，无需 license）：

```bash
python scripts/layout_scan_analysis.py \
  --baseline data_proxy \
  --scan L1_8x6=data_proxy_scan/8x6_dense \
  --scan L2_7x7=data_proxy_scan/7x7_zdense \
  --scan L3_9x7=data_proxy_scan/9x7_dense \
  --output analysis/layout_scan_report.md
```

把 `analysis/layout_scan_report.md` 发回（commit 或微信均可），即可做 go/no-go 判定。

**Step 3　全量 20 bin**（探针通过后再跑，3 × 20 = 60 次运行）：去掉 `--angles` 即可
（默认 20 bin）。若探针已足够判决，Step 3 可推迟到 surrogate 标定阶段。

注意事项：

- 若报 `build/` 不存在：`mkdir build`（ANSYS 临时工作目录放那里）。
- `data_proxy_scan/` 已加入 .gitignore——CSV/bins 不进仓库，只有报告回来。
- 自检基准：`data_proxy` 基线 10° 应为 PV=11.09mm、斜率RMS=6.59mrad；
  扫描脚本对基线的自比必须 = 1.000。

### 3.4 判定标准（10° 斜率比为主要指标）

| 结果 | 判定 | 后续 |
|---|---|---|
| L3 ≤ 0.35 且实测落在两模型包络内 | **Go（强）** | a⁴ 类标度可用 → 建解析 surrogate + FEA 稀疏标定 |
| 0.35 < L3 ≤ 0.55 | Go（弱） | 地板可动但标度偏软 → surrogate 需密集 FEA 采样 |
| L3 > 0.55 | **Kill** | 63 螺栓仍压不到一半 → 放弃布局轴，转玻璃厚度/场级分派 |
| L2 显著优于 L1（比值低 ≥15%） | 方向性有效 | 布局族按方向参数化（Q2 答：智能布置有价值） |
| L1 ≈ L2（差 <15%） | 只有密度重要 | 布局优化退化为"螺栓数量/成本"一维问题，反而更简单 |

## 4. 扫描通过后的完整路线（纲要）

1. **布局族参数化**：(每向螺栓数, margin, 可选非均匀间距) 低自由度族，
   限制在扭矩管/桁架可制造约束内；非均匀布局需扩展渲染器 C++ 侧（当前仅支持均匀网格）。
2. **跨布局形变 surrogate**：板理论解析项给一阶梯度 + 稀疏 FEA 采样标定；
   备选小 NN。这是 Phase 5 的主要技术风险。
3. **认证下界管线复用**：每个布局 → 重力 bins → 影响函数 → h\* 闭式补偿 →
   可微渲染算 B\*（36/110dir）。地板 B_floor 与可达带一起作为布局的"价格标签"。
4. **场级分派**：K 布局库 + 全场分派（North 镜惩罚 ≈1.00 无需加强，
   South/East/West 近场才是收益集中区）→ 成本-性能 Pareto 前沿。
5. **论文衔接**：Phase 0–4 的故事是"认证极限"，Phase 5 的故事是"优化极限本身"——
   完整回应导师"proxy 未起真正优化作用"的批评。

## 5. 风险与边界

- **制造约束**：真实定日镜螺栓位置受扭矩管/桁架限制；扫描阶段先不考虑，
  布局族设计阶段必须纳入（否则结论不可制造）。
- **θ 分量仍不可约**：布局只动地板和可达带，不动 §1.1.3 的 θ 变化分量；
  新布局下的 B\* 仍含该项，论证时勿过度承诺。
- **margin 是免费杠杆**：本次扫描固定 8% 以隔离变量；减小 margin 同时缩跨距与悬挑，
  是零螺栓成本的地板下移手段，留给布局族阶段。
- **ANSYS 工时**：全量 3 布局 × 20 bin ≈ 60 次运行；若单次 ~5 min 则 ~5 h，
  建议夜间跑；探针先行保证不浪费。
