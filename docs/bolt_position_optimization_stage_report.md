## 1. 背景与问题提出

### 1.1 为什么做位置优化

Phase 0–4 的诊断闭环确立了「固定布局下螺栓行程调节已到顶」：TPS 影响张量对重力畸变结构性正交，光学端到端回收率仅 13–16%，其余 84–87% 的 S95 差距是支撑布局/玻璃刚度决定的结构性硬地板（`docs/phase5_report.md` §1.1）。Phase 5 遂把结构参数变成优化变量，沿「margin 扫描 → 密度扫描 → 逐栓位置」三级推进：margin 是第一旋钮（m\*=0.05，逐镜红利 −26%~−29%），密度是第二旋钮（9×7=63 栓 @m05 甜点）。位置是第三个、也是最后一个未榨干的自由度。

Phase 5.4 的科学问题（`docs/phase5_4_bolt_position_optimization.md` §1）：

1. **均匀性是否最优？** 悬挑带承载 80–90% 斜率能量——螺栓集中边缘、中心稀疏，能否以更少的栓达到相同的 S95？
2. **非对称镜位是否需要专用布局？** East/West 镜全年穿越 ~45–46° NLGEOM 变号区，x/z 向最优栓距可能不同。
3. **与文献对话**：颜健组「N≥11 后改善可忽略」建立在均匀间距前提上；若栓可自由放置，递减回报是否取决于*位置*而非*数量*？核心假设为「**位置 >> 数量**」。

Phase 6 在 5.4 收口的基础上再进一步（`docs/phase6_pos_height_joint.md` §1）：5.4 只动过「删哪些栓」（组合）与「整线平移」（12/20 DOF），从未让单栓自由；且 A4 的 −0.8% 只是线级残余，逐栓级未知。Phase 6 对全部 Nb 根栓的**位置 (x_b, z_b) 与行程 h_b 同时端到端优化**，期望产出随镜位（NEWS）不同的非对称布局。

### 1.2 与论文主线的关系、为何收口

论文叙事主线为「理想曲面无工程参考价值 → 嵌入物理信息的可微渲染优化 → 重力形变下最优面型」，结构层只保留 margin 守恒律（+ 地板认证 + 逐镜红利）作为 AEI 主叙事，密度甜点与稀疏规则降级为设计建议节。位置优化支线的最终结论是**负结果封顶**——「位置 >> 数量」强形式证伪、弱形式红利有限（−7.7%）、连续精修残余 ~0.5–0.9%——其价值主要是设计规则（均匀网格近优）而非新红利源，不足以支撑论文主线篇幅，故收口存档。两种结果本均可发表（门体系的设计意图，`docs/phase5_4_bolt_position_optimization.md` §4），本支线实际落在「证伪/封顶」一侧。

双轨架构（`docs/phase5_4_implementation_plan.md` §2.3）：**Track B（主线）稀疏化免梯度**——存在性变量只改 BC 不动网格，headline 问题不依赖位置梯度；**Track A（副线）位置梯度精炼**——隐函数定理 `∂d/∂π = K⁻¹(∂f/∂π − ∂K/∂π·d)` 链式传播至 S95。两轨在「幸存者位置精炼」（A4）汇合。

关键基建（§3.3.1）：布局 schema 三形式（grid/lines/free，`scripts/layout_utils.py`）；渲染器 `kMaxBolts` 50→128、`loadBin` 尺寸硬校验、`bolt_l1_lambda` L1 近端、`dump_surface_grad` 面梯度 dump。**幻影支撑纪律**：渲染器内置行程零 ≠ 移除栓——支撑移除只通过外环重力场重解生效，一切稀疏结论必须过外环重解才是物理诚实的。

### 2.2 ROM → ANSYS 真值口径

布局循环需要廉价重力场评估器（ANSYS 每布局 2.5–5h 不可进循环），Phase 5.2/5.4 期间研制 von Kármán 板 FEM ROM。其渲染级精度：满网格/边缘完整布局逐镜 0.1–2.6%（可用），含大跨度无支撑边缘区的剪枝布局场幅值 **4× 失真**（v3 sparse74 事故）。鉴于仅在受限有效域内与真值一致、无独立仿真价值，ROM 已于 **2026-08-06 整体退役删除**（`phase5_report.md` §3.4）。确立的两阶段规程：**评估器外环探索 + ANSYS 细子步真值锚定终裁**；真值生成纪律为准静态一律 `--nsubst 50,500,50`（粗子步跳支伪影教训）。本报告中所有标注 ROM 口径的数字保留为实验日志，最终结论均以真值为准。

### 2.3 Phase 6：TPS 位置灵敏度直接法（零 C++ 改动）

Phase 6 不复活 ROM，位置梯度走 **TPS 红利基的伴随灵敏度**（`docs/phase6_pos_height_joint.md` §2.2）：前向 `w(r) = w₀(θ; π₀) + Σ_b h_b·φ_b(r; π)`，φ_b 为 TPS 基数样条（FEA 验证过的生产代理）；φ_b 对栓位 π 光滑（TPS 线性系统 `A(π)·[c_b; d_b] = [e_b; 0]`），由渲染器 dump 的逐太阳面梯度收缩得 `∂L/∂π`（一次伴随求解/栓，NB 次 38–102 阶回代，numpy 秒级）。这是 RBF 网格变形/形状优化领域的标准工具（离散伴随 + RBF 节点灵敏度），且无需重验证前向物理。

架构为两时间尺度双层循环（§3）：内环固定 π 优化 h（GPU 100-iter Adam）；外环 dump → 伴随收缩 → Adam-π 步进（约束投影）→ TPS bins 重生成（<1s）→ 回内环；终裁走 ANSYS 细子步真值锚。重力场在内外环期间冻结于初值真值 bins，其量级由 G0b 门量化（见 §4.1）。约束：栓距 ≥0.8m、栓位距板边 ≥0.35m、边缘带相邻栓距 >1.2m 拒步（防 v3 型边缘天窗）；不设对称性约束。

**真值终裁（G5 表，`phase5_report.md` §3.3.3）**：贪心 v3-74 真值口径四镜 **N 96.80 / E 117.62 / S 130.14 / W 118.21**——相对基线全面灾难。根因：贪心按行程排名删除了两个整列（x≈−3.47 列 6 栓、x≈+4.62 列 5 栓）与底排 5 栓，**底排被开出 6.93m 无支撑跨度**，真值 10° 边缘 flap 下垂 **31.2mm**（ANSYS 原生）；ROM 对该 flap 模态幅值低估 4×（7.66 vs 31.2mm）——门体系按设计拦截了错误结论。

**核心教训：作动器效用 ≠ 支撑效用**。99 栓优化后 min max|h|=1.3mm——TPS 单位分解把行程摊派到所有作动器，零栓「自然」可剪；按行程排名剪栓删除的是「行程小但支撑关键」的栓。稀疏必须主动逼迫，且必须区分「作动器稀疏」与「支撑稀疏」。

**设计规则（弱形式成立的内容）**：「边缘栓一根不能动、内部栓约 10% 冗余」（99→91，−8/99 ≈ 8% 内部冗余实删）。

「位置 >> 数量」命题的最终裁决链：**贪心自由化证伪（v3）→ 边缘保护稀疏有效但有限（v4，−7.7%）→ 连续位置精炼残余 ~0.8% 封顶（A4）**——均匀网格 + margin 最优 + 密度甜点即设计空间的事实最优区，位置微调不存在隐藏红利。

## 4. Phase 6 实验与结果（2026-08-06～08-07）

> 出处：`docs/phase6_pos_height_joint.md`「Phase 6 实验结果」节。主批口径：36dir、North/West 双镜、渲染器 S95（重力冻结于初值真值 bins）。

### 4.1 门验证（G0a / G0b / G1 通过）

- **G0a（TPS 位置灵敏度正确性）**：直接灵敏度法（∂A/∂π 复步长 + A⁻¹ 回代），FD 对照 **cos = 1.000000、norm_rel = 3.4e-4**（9×7 满 126 参数 + v4-91 自由布局双 PASS）。脚本 `scripts/tps_position_sensitivity.py`。
- **G0b（重力-位置灵敏度，ANSYS 细子步 FD）**：±0.4m 扰动 → Δw₀ 斜率 RMS 0.18mrad@10°（~6%/0.1m）；**重力通道比 TPS 作动器通道小 ~4×**——「冻结重力内环 + ANSYS 终裁外环」架构量级成立。附带发现：ANSYS patch 在 0.2m 网格上的节点量化使 <0.1m 扰动不可分辨（真值生成栓移须 ≥0.4m 穿量化）。
- **G1（margin 方向 sanity）**：组装 dL/dmargin = **+832**（North @36dir），符号与量级同真值 margin 曲线 FD（+465 全镜口径）一致。

### 4.2 bold top-K 阶梯协议

首版小步长归一化协议（`scripts/pos_joint_optimize.py`）无效：步幅被自锁到 mm 级，位置效应 ≤0.2% 且多在噪声地板内，无法区分「无位置效应」与「步幅不足」——必须用 bold 阶梯证伪（附录 A.1，仅作协议演进记录）。终版 **bold top-K 阶梯协议**（`scripts/pos_joint_optimize_bold.py`）：每步仅动梯度 top-8 坐标，阶梯 {0.01–0.30m}，固定 h 确定性评估，改善即接受、接受后重优化行程。多初值批：{9×7, 9×8, 8×8, 10×7} × {N, W}，36dir，bold 4–8 步。

### 4.3 四初值批结果：1–3 步触底，位置精修 ~0.5–0.9%

联合最优 S95 @36dir（§2 表）：

| 初值 | North（s0→best） | West（s0→best） | 触底步数 |
|---|---|---|---|
| 9×7 (63) | 46.499 → 46.059 | 61.738 → 61.280 | 1–3 |
| 9×8 (72) | 46.321 → **45.890** | 61.591 → **61.182** | 1 |
| 8×8 (64) | 46.570 → 46.219 | 61.894 → 61.360 | 多步振荡 |
| **10×7 (70)** | 46.219 → **45.810** | 61.493 → **61.049** | 1 |

- **位置精修效应**：每布局 −0.2~−0.45 m²（**~0.5–0.9%**），1–3 个 1–3cm 小步后触墙（更大步幅全回退）——优化器在给足 30cm 自由时只走 1–3cm。
- **网格排序**：10×7 > 9×8 > 9×7 > 8×8（N/W 一致）——**10×7（70 栓）为当前最优初值**（N 45.81 / W 61.05 @36dir）；9×7 的「密度甜点」地位被 10×7 超越。
- **无不对称布局涌现**：最优布局离均匀网格平均位移 ~1–3cm 即停，无随镜位分化（小步长版位移 15–30mm 在整板尺度上几乎不可见，图 `analysis/figures/fig_p6_results.png`）。

### 4.4 Phase 6 判读（情景 C 修订版收口）

1. 「均匀网格近优」成立且被 bold 协议强化——**位置是 ~1% 级精修手段，不是红利源**；小步长版「≤0.2% 无位置效应」的表述修正为「~1% 精修效应」。
2. 「9×7 密度甜点」修正为**「密度 × 长宽比二维面」**：10×7（70 栓）在 N/W 双侧均优于 9×7，密度扫描应补 10×7/9×8 等点。
3. 遗留警告：重力通道冻结使「重力主导的位置效应」上限被钉在 G0b 量级（4× 次级）；G3/G4 门按数据不进入（G2 未达「S95 单调改善」判据）。
4. 网格选择 >> 位置微调——与 A4 的 0.8% 封顶互证，「均匀网格 + m05 + 密度面」在逐栓自由化层面获得最终确认。

## 5. 总结论与设计规则

**对「位置 >> 数量」假设的完整裁决**：强形式证伪（G4：同 N 均匀 72 逐镜优于贪心 74；v3 真值灾难）；弱形式成立（v4 边缘保护 99→91，真值 vs 基线逐镜 N −7.3%、E −9.4%、S −13.3%、W −0.1%）；连续精修残余 ~0.8%（A4 线级）/ ~0.5–0.9%（Phase 6 逐栓级）封顶。

可写入论文设计建议节或工程设计文档的规则：

1. **均匀网格近优**：在「margin 最优 + 密度甜点」之后，逐栓位置是 ~1% 级精修手段，不存在隐藏红利；优化器给足 30cm 自由只走 1–3cm。
2. **边缘栓一根不能动，内部栓约 10% 冗余**：悬挑带支撑完整性是硬约束（v3 的 6.93m 无支撑底排 = 31.2mm flap 灾难）；99 栓致密布局内可删 ~8 根内部栓（v4-91），红利集中在 E/W 镜。
3. **作动器效用 ≠ 支撑效用**：行程小的栓可能支撑关键；任何按行程排名的剪枝必须过外环重力场重解（幻影支撑纪律），且结论以 ANSYS 细子步真值为准。
4. **密度选择是二维面而非一维甜点**：密度 × 长宽比共同决定地板；当前证据下 10×7（70 栓 @36dir N/W 双侧最优）优于 9×7（63 栓），密度扫描应补 10×7/9×8 点。
5. **方法资产（可复用）**：「评估器外环 + 真值锚定终裁」两阶段规程；细子步真值生成纪律（`--nsubst 50,500,50`，粗子步跳支伪影教训）；门体系裁决范式（G4 同 N 受控对照是「位置 vs 数量」归因的关键设计）；TPS 伴随位置灵敏度（cos=1.000000，秒级，可复用于其他布局类问题）。
