# D1: 螺栓梯度有限差分验证

## 目标

验证 AD（自动微分）计算的螺栓梯度 $\partial L/\partial h_b$ 与 FD（有限差分）一致，确认可微优化管线的梯度可靠性。

## 现有代码审计

### 已验证无问题的部分

| 检查项 | 结论 |
|--------|------|
| FD 中心差分公式 `(f(h+eps)-f(h-eps))/(2*eps)` | ✅ 正确 |
| AD 梯度路径: clearFluxGradient → loss gradient → boltBackwardPass | ✅ 正确 |
| computeEnergyLossGradient(1.0f) 产生 dL/df=1（验证 total flux sum 梯度） | ✅ 正确 |
| computeS95Loss(s95Level) 固定阈值比较（AD 也不微分阈值） | ✅ 一致 |
| Push constant 大小（新旧均为 16 bytes） | ✅ 兼容 |

### 发现的问题

| # | 问题 | 严重程度 | 影响 |
|---|------|:---:|------|
| **P1** | `boltForwardSurface(1.0f)` 硬编码 — 验证时始终使用 0° 重力，与实际太阳方向不匹配 | 中 | cosθ 不准确导致重力项有偏差，可能影响 FD 精度 |
| **P2** | 仅测试一个 sun direction + 一种 init 配置 | 低 | 覆盖面不足，无法评估梯度质量随角度/配置的变化 |
| **P3** | eps 固定 2mm，未做收敛性分析 | 低 | 可能不是最优步长 |

### 根本原因分析

梯度符号不一致（Test 1: 45.7%, Test 2: 74.3%）的根本原因在光学端：

- **2 层玻璃光学的 TIR 分支**：当表面微扰导致某些光线穿过 TIR 临界角边界时，光线路径从"折射-反射-折射"跳变到"简单反射"，这在数学上是不可微的
- **Slang `bwd_diff` 的局限**：对不同分支采用相同的导数公式，在分支边界处产生错误的梯度
- 这已被 `differentiable_rendering_discontinuity_analysis.md` 记录

> ⚠️ **工程约束**：2 层玻璃折射模块是定日镜光学模型的必要组成部分，不可关闭或简化。玻璃反射率 (~4% per surface) 和吸收对总光学效率有显著影响，移除玻璃折射会使能流计算产生系统性偏差。本实验的目标是在**保留完整玻璃光学**的前提下，**量化**可微渲染的梯度质量，明确其适用范围和局限性。

## 实验流程

### Step 1: 修复 P1 — 使用正确的 cosθ

将 `verifyBoltGradients()` 中的 `boltForwardSurface(1.0f)` 替换为实际 cosθ 计算。

### Step 2: 多角度梯度验证

对 3 个重力角度分别运行梯度验证：

| 太阳方向 | cosθ | 重力角度 | 测试目的 |
|---------|:---:|:---:|------|
| (0.0, 1.0, 0.0) | ~1.0 | 0° | 最大重力，基准 |
| (0.5, 0.707, 0.5) | ~0.71 | 45° | 中等重力，插值点 |
| (0.707, 0.259, 0.707) | ~0.26 | 75° | 最小重力，边界 |

### Step 3: 多配置测试

对每种角度测试 2 种 bolt 初始化：
- **Zero init**: 全部 h=0（只有重力，最接近物理）
- **Elliptic-like**: 从椭圆拟合的螺栓高度

### Step 4: eps 收敛性扫描

对代表性的 3 个螺栓（角部 bolt 0、边缘 bolt 3、中心 bolt 17），扫描 eps ∈ [0.5, 1, 2, 5, 10] mm，观察 FD 梯度 vs AD 梯度的收敛行为。

### Step 5: 综合报告

汇总所有测试结果，给出梯度质量的总体评估。

## 判定标准

| 指标 | 通过阈值 | 说明 |
|------|:---:|------|
| 符号一致率 (S95 loss) | > 70% | 至少大部分螺栓梯度方向正确 |
| 余弦相似度 (S95 loss) | > 0.4 | 梯度向量大致指向正确方向 |
| 符号一致率 (Flux sum) | > 60% | 总能量梯度方向 |
| 多角度一致性 | 符号一致率波动 < 15% | 梯度质量不随角度变化 |

> 注意：由于已知的光学端 TIR 分支问题，完美梯度 (>90%) 在 2 层玻璃模型下不可达。本实验的目标是**量化**梯度质量，而非修复它。
