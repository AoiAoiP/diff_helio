## 1. 代码考古：三个决定设计的事实

### 事实一：布局 100% 经由离线 bin 文件进入渲染器

渲染器主路径从不计算螺栓坐标——面型完全由预计算 `influence_phi*.bin`（NB×32×32 float32）与 20 角度 3-plane 重力 bins 决定（`src/pipeline.cpp:495-591`）。`bolt_margin`/`num_bolts_x/z` 对主渲染路径是惰性键（唯一消费坐标的 C++ 代码是 WoS 验证 pass，`pipeline.cpp:1162-1178`）。

**推论**：任意坐标布局的改动面几乎全在 Python 数据生成侧；渲染器只需 `num_bolts` 与 bins 一致即可直接跑。

### 事实二：数据管线底层已支持任意坐标，入口层只暴露了规则网格

- TPS：`proxy/tps_pipeline/tps_solver.py:27-66` `build_system(bolt_x, bolt_z)` 接受任意坐标数组；入口 `generate_proxy_model.py:68-74`（`compute_bolt_positions` linspace）与 `:705-715`（`_resolve_bolt_params`）假设规则网格——**浅改**。
- ANSYS：`ansys_gravity.py:56-70`（`bolt_positions` linspace）假设规则网格，APDL patch 循环（`HALF_WIN=0.3`，`:163-168`）本身与布局规则性无关——**浅改**。
- 布局 JSON schema（`bolts_x/bolts_z/margin`）三个消费方共享，需扩展坐标数组键。
- **ROM 是唯一短板**：`rom_plate_fem.py:82-109` `make_mesh(margin)` 只收标量 margin、栓数 7×5 硬编码（`:107-108`）。

### 事实三：隐函数梯度的原材料已就位，但有两个坑

可复用件：

- `K`/`Km` 显式稀疏组装（lil→csr，`rom_plate_fem.py:120-136, 251`），`solve_lu = spla.factorized(Kff)`（`:156`）——现成的 K⁻¹ 回代算子；
- `self.elem`/`self.elem_m` 逐元记录 `(i,j,ax,bx,dofs)`（`:131, 238`）——逐元求 `∂K_e/∂π` 的现成钩子；
- 网格节点是布局的分段线性函数（栓线±patch 边线为硬线，bay/悬挑等距内插，`:86-106`）——`∂mesh/∂π` 稀疏且解析可得；
- alpha 表在 provider 侧后乘（`rom_field_provider.py:83-89`），与布局无关，不阻碍求导。

两个坑：

1. **节点塌缩**：硬线集合是 Python `set`（`:89-95`），相邻栓距 → 2·patch_hw 时 patch 边线重合 → 节点数突变 → DOF 维数跳变、梯度不存在。margin 参数化下不触发，**逐栓自由移动必然触发**。
2. **VK 无联合切线**：`solve_vk`（`:298-333`）是交替块迭代 + Aitken，收敛点没有现成的全耦合雅可比；线性板灵敏度平凡，VK 灵敏度需补 `_nl_mem_rhs` 对 `d_b` 的交叉切线（或接受冻结近似）。

### 额外发现：幻影支撑问题（Track B 的核心物理陷阱）

在渲染器内把某栓行程置零 ≠ 移除该栓——重力 bins 生成时该栓仍是 patch 支撑（w=0 约束）。**支撑移除只通过 ROM/ANSYS 重解重力场生效**。任何"行程 LASSO 剪枝"结论必须经外环重力场重解才是物理诚实的，否则稀疏红利被幻影支撑高估。

## 2. 总体架构

### 2.1 布局参数化三级

| 级 | 参数 | 自由度 | 回答的问题 | 网格后果 |
|---|---|---|---|---|
| L0 | margin 标量 | 1 | 悬挑-跨距守恒（已完成） | 张量网格，无风险 |
| **L1** | 7 条 x 栓线 + 5 条 z 栓线 | **12** | E/W 镜 x/z 向最优间距是否不对称；非均匀行列间距是否有红利 | 张量网格，保拓扑 |
| **L2** | 逐栓 (x,z) + 存在性 s_b | ≤70+99 | "位置 >> 数量"（主问题） | 并集张量网格，需防塌缩 |

L2 网格构造：xs = sort(∪{x_b} ∪ {x_b±hw} ∪ {0,W})，zs 同理——每栓必为网格节点，张量积结构保留，无需非结构网格。网格规模上界 ~（2·99+2)×(2·99+2) 节点、30k DOF，稀疏 LU 仍秒级。

### 2.2 防塌缩参数化（L1/L2 共用）

不直接优化坐标，优化**间隙**：`gaps = softplus(g) + δ_min`，`positions = cumsum(gaps)`（两侧悬挑间隙同理）。保证：栓序不变、最小间距 δ_min = 2·patch_hw + bay_min ≈ 0.8 m 恒成立、网格节点数恒定（拓扑固定）→ 梯度处处存在。投影/约束代码由此消失。

### 2.3 两条执行轨道（与策略文档的偏差及理由）

策略文档按 G0→G5 线性排布（隐函数梯度先行）。考古结论支持**重排为双轨**：

- **Track B（主线，稀疏化）可以免梯度**：存在性变量 s_b 只改 BC 刚度、不动网格几何——`∂K/∂s_b` 平凡且与网格无关；v1 甚至可用"行程-LASSO + 外环 ROM 重解"完全免梯度。**headline 问题（位置>>数量）不依赖位置梯度**。
- **Track A（副线，位置精炼）才需要隐函数梯度**：x/z 坐标动 → 网格几何动 → `∂K/∂π`、`∂f/∂π` 全链条。

两轨在"幸存者位置精炼"处汇合。收益：主线风险与副线解耦，G0 失败不再阻塞 G3/G5。

```
S0 数据管线任意坐标化 ──► T0 ROM 任意布局网格 ──► G1' 非均匀布局真值门
     │                            │
     ├─ Track B（主线）──────────► B1 L1近端 → G2 合成支撑恢复 → B3 稀疏外环 → G3/G4 → B4 真值复核 G5
     └─ Track A（副线）──────────► A1 隐函数梯度 G0 → A2 ROM级L1试点 → A3 渲染级收缩 → A4 幸存者位置精炼
```

## 4. Track B（主线）：99 栓致密起点的 Group LASSO 稀疏化

### 4.1 物理一致化设计

- **起点**：`configs/bolt_layouts/density/11x9_margin05.json`（99 栓，已存在）。99 栓足以覆盖"边缘密+中心疏"的任何 25–35 栓子集。
- **存在性参数化**：
  - **v1（默认，免隐函数梯度）**：位置固定，Group LASSO 退化为逐栓 L1（group={h_b}）。被压零的栓 = 候选删除 → **外环 ROM 重解重力场**（消除幻影支撑）→ TPS 按幸存布局重生成（φ 是栓集的红利基函数，删栓改变所有 φ，必须重出，<1 s）→ 渲染器重优化。迭代至无可删栓。
  - **v2（可选升级）**：弹簧软存在 `K += k_max·s_b`（patch DOF 上），`∂K/∂s_b` 平凡、网格拓扑固定，s_b 进内环梯度——与 Track A 汇流后再启用。
- **渲染器内环**：99 维 h 的 Adam + L1 近端。`tanh` 参数化下 prox 须作用在物理 h 空间。

### B1 渲染器 L1 近端（小改动，0.5 人日）

| 文件 | 改动 |
|---|---|
| `shaders/bolt_optimizer.slang` | Adam 步后加软阈值：`h ← sign(h)·max(|h|−λ_L1·lr_eff, 0)`（物理空间，ε 随之重算）；~15 行 |
| `src/config.{h,cpp}` / `src/pipeline.cpp` | 新键 `bolt_l1_lambda`（默认 0，0 = 逐位退化为现行为）；push constans 传递 |
| 备选 | 零代码回退：外环贪婪后向消除（按 \|h_b\| 排序逐轮删最小者）——非 LASSO 但可用，留作 B1 失败兜底 |

**G2 合成支撑恢复门**（λ 路径正确性的单元测试）：

- 构造已知真解：`d_target = Σ_{b∈S*} h*_b·φ_b`，S* = 人工选 25 栓（边缘密中心疏），h* 随机行程 ∈ [5, 30] mm；
- 用 B1 的 prox-Adam 在斜率空间目标 `‖∇(Σ h_b φ_b) − ∇d_target‖² + λΣ|h_b|` 上从 99 栓恢复；
- **判据**：λ 路径上存在 λ 使支撑恢复 precision 且 recall ≥ 0.9；不达 → prox/λ 调度实现有误，修完才准进 B3。

### B3 稀疏外环驱动（新脚本 `scripts/sparse_layout_optimize.py`，骨架复用 `rom_margin_optimize.py`）

```
π⁰ = 11×9 @ m05（99 栓），k=0
loop:
  1. ROM provider --bolt-layout πᵏ → 20 角 3-plane bins（v2 alpha 细表）   [~15 min]
  2. TPS 重出 πᵏ 的 influence_phi*.bin                                     [<1 s]
  3. 渲染器：num_bolts=|πᵏ|, bolt_l1_lambda=λᵏ, 100 iter × NEWS 4 镜 @110dir [~35 min]
     （零初始化即可——Phase 5.2 已证 100 iter init 无关性）
  4. 剪枝：S = {b : |h_b| < τ}；对 S 逐栓做 ROM 级删除代价评估（斜率 RMS 增量 <2% 才真删）
  5. λ 调度：λᵏ⁺¹ 按 λ 路径递增；无可删栓 → 收敛
```

- 每轮 ~50 min，预计 4–6 轮（99 → ~40 → ~30 → 收敛），单日内完成。
- 热启动链复用现有机制，但栓数变化时需按坐标映射 h（最近邻），而非整文件传递。
- 产出：`analysis/sparse_path.csv`（每轮：N、四镜 S95、λ、删栓清单）。

## 5. Track A（副线）：位置隐函数梯度与精炼

> 与主线并行；任一环节失败不阻塞 Track B。

### A1 ROM 隐函数梯度（G0，1.5–2 人日）

新脚本 `scripts/rom_layout_sensitivity.py`，分两级：

1. **线性板（精确）**：`∂d/∂π = Kff⁻¹(∂f/∂π − ∂Kff/∂π·d)`。复用 `solve_lu` 回代；`∂K_e/∂π` 逐元组装——对 `acm_element` 的 `(ax,bx)` 用复步长差分（元素函数是纯函数，复步长到机器精度），`∂(ax,bx)/∂π` 由 T0 的节点溯源表解析给出；`∂f/∂π` 一致载荷 ∝ ax·bx 精确。
2. **VK（两档）**：v1 冻结近似——收敛点冻结膜态与几何刚度，只对最终弯曲步求灵敏（`∂Kg/∂π` 仅穿几何）；v2 联合雅可比——残差 `R(d_b,d_m;π)=0` 的全雅可比（`Kg` 已有，缺 `_nl_mem_rhs` 对 `d_b` 的交叉切线，~60 行）。

**G0 判据**：单栓 x 坐标扰动 ±1 cm，FD vs 解析相对差 <10%（线性板应达 ~1e-5 量级——用作实现自检；VK 冻结近似若超 10% → 上 v2 联合雅可比；仍不达 → Track A 整体降级为免导数：ROM 斜率目标上 CMA-ES，4 探针角每次评估 ~3 min，可行但慢）。

### A2 ROM 级 L1 试点（0.5 人日，零渲染器依赖）

12 DOF 线布局（7 x 线 + 5 z 线，softplus 间隙参数化），目标 = 4 探针角加权斜率 RMS（重力场投向地板的代理），Adam + A1 梯度。产出"ROM 预测最优非均匀线距"。**这本身就是对 E/W 不对称间距问题的第一个回答**，且把 S0/T0/A1 全链路在廉价目标上预演一遍。

### A3 渲染级梯度收缩（1 人日）

梯度链：渲染器已有逐像素 `∂L/∂(y,yu,yv)` 与 `reduceSurfaceGradients` 归约——**面梯度即重力场梯度**（w = w₀ + Σhφ，∂L/∂w₀ ≡ ∂L/∂w）。

| 改动 | 说明 |
|---|---|
| `src/pipeline.cpp` 新键 `dump_surface_grad` | 末迭代逐太阳方向 dump 面梯度（numSuns×3×32×32 float32，334dir ~4 MB） |
| `scripts/layout_gradient.py` | 太阳方向→倾角 θ(t)→角度 bin 权重（与 shader `sampleGravityUY` 同双线性）→ 与 ROM `∂w₀/∂π`（含 binning 的 σ 平滑+中心差分，线性算子可同穿）收缩得 `dL/dπ` |
| sanity | m05 处 dS95/dmargin 应与 v2 细表曲线（276.8@04 / 291.3@05 / 308.9@06）的 FD 符号、量级一致 |

### A4 幸存者位置精炼（0.5 人日 + ~4 h GPU）

Track B 稀疏终局的幸存栓做 L2 自由化：group 扩展为 `{h_b, w_x·Δx_b, w_z·Δz_b}`（恢复策略文档的 Group LASSO 原形），softplus 间隙约束，A3 梯度 + Adam，30–50 iter。**判读**：位置移动带来 >2% 的进一步 S95 下降 → "自由化红利"成立；<2% 或自发回到近均匀 → "稀疏化拿大头、位置微调无增量"（反向证明均匀网格在固定支撑集上的局部最优性）。

## 8. 风险登记册

1. **幻影支撑**（最高危）：渲染器内 h_b=0 不移除重力场支撑——所有稀疏结论必须过外环 ROM/ANSYS 重解，论文中明确区分"作动器稀疏"与"支撑稀疏"。
2. **节点塌缩**：softplus 间隙参数化（δ_min≈0.8 m）结构性消除；T0 验收含节点数恒定性断言。
3. **alpha 表传递**：v2 细表 m04-only 标定，对 99 栓高密度布局 w/t 更小 → alpha 系统性偏差（m06 实测 +16% 方向）——ROM 口径内部比较公平；G5 真值裁决绝对水平。
4. **粗子步跳支**：G1'/G5 全部 ANSYS 生成必须 `--nsubst 50,500,50`（§3.8 教训，写入执行清单检查项）。
5. **VK 联合雅可比工作量**：冻结近似先行、G0 裁决，避免一次性投入。
6. **99 栓渲染器兼容**：bin 尺寸校验（S0）+ shader NB 硬编码排查（S0 检查项）；99×3×4 KB 显存无压力。
7. **λ 调度敏感性**：λ 路径全量记录（`analysis/sparse_path.csv`），取膝点而非单点结论。
8. **亚网格悬挑**：m05 悬挑 0.32/0.24 m ≈ 渲染格 0.40/0.30 m——相对比较公平，绝对残差略低估（继承 Phase 5.1 遗留注意）。
