# North 300m σ_slope 灵敏度实验报告

> 日期：2026-07-22
> 实验：North 300m, 200 iter, lr=4e-4 constant, Buie CSR=0.01, SPP=1024
> 硬件：RTX 4070 SUPER
> 相关文档：[[slope_error_recalibration]]

## 1. 实验设计

测试 5 个 σ_slope 值，从激进（0.2 mrad）到保守（1.5 mrad），覆盖传统标定值（1.0 mrad）和推荐值（0.5 mrad）。

| 实验 | σ_slope | 光束宽度贡献 | 物理含义 |
|---|---|---|---|
| A | **0.2 mrad** | 3% | 激进—仅镜面粗糙度 |
| B | **0.5 mrad** | 17% | 推荐—亚网格残余 |
| C | **0.8 mrad** | 35% | 过渡—部分重力+制造 |
| D | **1.0 mrad** | 45% | 基线—传统集总值 |
| E | **1.5 mrad** | 65% | 保守—含对准/跟踪误差 |

## 2. 原始结果

|---|---|---|---|---|---|

## 3. 核心发现

### 3.1 S95 与 σ_slope 的关系

```
σ=0.2 → S95=21.1 m²  (最佳)
σ=0.5 → S95=27.9 m²  (+32%)
σ=0.8 → S95=39.4 m²  (+87%)
σ=1.0 → S95=50.0 m²  (+137%)
σ=1.5 → S95=86.4 m²  (+310%)
```

S95 随 σ_slope 近似二次增长（R²≈0.997），与理论预测一致：光束宽度 ∝ √(σ_sun² + 4σ_slope²)，S95 面积 ∝ 光束宽度²。

### 3.2 螺栓行程惊人一致

| σ (mrad) | Max (mm) | Mean (mm) | RMS (mm) |
|---|---|---|---|
| 0.2 | 34.97 | 15.62 | 18.52 |
| 0.5 | 35.52 | 16.01 | 18.91 |
| 0.8 | 35.12 | 15.66 | 18.63 |
| 1.0 | 35.68 | 15.70 | 18.66 |
| 1.5 | 36.38 | 16.06 | 18.98 |
| **Range** | **1.41** | **0.44** | **0.46** |

**所有 5 组实验的螺栓最大行程在 34.97–36.38 mm 之间，差异仅 4%！**

螺栓 stroke 的 pairwise RMS 差异：

| | σ=0.2 | σ=0.5 | σ=0.8 | σ=1.0 | σ=1.5 |
|---|---|---|---|---|---|
| σ=0.2 | — | 0.476 | 0.298 | 0.416 | 0.665 |
| σ=0.5 | 0.476 | — | 0.390 | 0.583 | 0.581 |
| σ=0.8 | 0.298 | 0.390 | — | 0.494 | 0.699 |
| σ=1.0 | 0.416 | 0.583 | 0.494 | — | 0.476 |
| σ=1.5 | 0.665 | 0.581 | 0.699 | 0.476 | — |

所有 pairwise RMS 差异均小于 0.7 mm（<2% of max stroke）。

### 3.3 关键洞察：S95 是 σ 依赖的"货币"

Init S95 同样随 σ 变化：从 181 m²（σ=0.2）到 272 m²（σ=1.5）。这是因为**初始（零螺栓）flux 已经包含 σ 决定的模糊**。

这意味着：
- **不能直接跨 σ 比较 S95**——每个 σ 值定义了不同的"S95 货币"
- 优化器在所有 σ 值下都找到了相似的螺栓配置（max stroke ~35-36mm，RMS 差 < 0.7mm）
- 优化器受限于 L4 tanh 参数化的 40mm 上界——所有配置都接近此界

|---|---|---|---|---|---|

| 5 | 147.3 | 159.3 | 179.1 | 195.9 | 244.6 |

收敛速度（达到最终 S95 的 90%）：
- σ=0.2: ~45 iter
- σ=0.5: ~50 iter
- σ=1.0: ~55 iter
- σ=1.5: ~65 iter

**更小的 σ 收敛更快**（因为梯度信噪比更高，每轮看到的"信号"更清晰）。

## 4. 解释：为什么螺栓配置几乎不变？

### 4.1 tanh 界限制了探索空间

L4 参数化限制 max_stroke ≤ 40mm。所有 5 组实验的最优解都在 35-36mm，说明优化器在**所有 σ 值下都想达到更大的螺栓行程**，但受限于物理可实现性约束。

优化器找到的配置是：
```
"在 40mm 行程限制内，尽可能让 S95 最小化"
```

这个约束在所有 σ 值下都是 binding 的，所以最终螺栓配置高度一致。

### 4.2 光束宽度分解

| σ (mrad) | 2·σ_slope (mrad) | σ_sun (mrad) | σ_total (mrad) | slope/total |
|---|---|---|---|---|
| 0.2 | 0.4 | 2.2 | 2.24 | 3.1% |
| 0.5 | 1.0 | 2.2 | 2.42 | 17.1% |
| 0.8 | 1.6 | 2.2 | 2.71 | 34.8% |
| 1.0 | 2.0 | 2.2 | 2.97 | 45.3% |
| 1.5 | 3.0 | 2.2 | 3.72 | 65.0% |

σ=1.5 时，斜率误差主导了光束宽度（65%）。σ=0.2 时，太阳形状绝对主导（97%）。这就是为什么 S95 变化如此剧烈——**σ 直接改变了模拟器中的物理光束宽度**。

### 4.3 等效 S95 换算

如果我们假设真实物理的 σ_true ≈ 0.5 mrad，那么用不同 σ 优化出的螺栓配置，在 σ=0.5 的"真实世界模拟器"中评估，预期 S95 应该非常接近（因为螺栓配置本身相似）。

## 5. 结论与建议

### 5.1 主要结论

1. **σ_slope 控制的是 S95 的"计量单位"，而非优化方向。** 所有 σ 值下优化器找到了几乎相同的螺栓配置（RMS 差 < 0.7mm），因为 tanh 界是 binding 约束。

2. **不能通过跨 σ 比较 S95 来判断哪个 σ 更优。** S95=21（σ=0.2）和 S95=50（σ=1.0）代表的是同一种螺栓配置在不同模糊程度下的模拟结果。

3. **σ_slope 的选择影响优化行为而非优化结果。** 更小的 σ 让梯度更清晰、收敛更快，但最终螺栓配置几乎不变（对于 binding 约束的问题）。

4. **σ_slope 应基于物理残余误差标定，而非通过优化 S95 来"调参"。** 推荐值 0.5 mrad 基于：镜面粗糙度(0.15) + 亚网格波纹度(0.30) + TPS残余(0.20) 的 RSS。详见 [[slope_error_recalibration]]。

### 5.2 推荐

| 场景 | σ_slope | 理由 |
|---|---|---|
| 日常优化（推荐） | **0.5 mrad** | 物理标定值，平衡准确性与收敛速度 |
| 与传统结果对比 | **1.0 mrad** | 匹配历史基线，兼容已有实验 |
| FEA 验证/生产 | **0.5 mrad** | 当 TPS 代理被 POD-ROM 替代后，可进一步降至 0.3 mrad |
| 应力测试 | 0.2 mrad | 验证优化器在极端清晰度下的行为 |

## 附录：有效光束宽度与 S95 的理论关系

对于圆柱接收器上的点聚焦：

```
σ_total² = σ_sun² + (2·σ_slope)²
S95 ∝ σ_total² ∝ σ_sun² + 4·σ_slope²
```

其中 σ_sun ≈ 2.2 mrad（Buie CSR=0.01 的有效宽度）。

拟合实验数据：
```
S95(σ) ≈ a + b·σ²
```

| 参数 | 拟合值 |
|---|---|
| a (截距, σ→0 极限) | **~18 m²** |
| b (斜率系数) | **~30 m²/mrad²** |

即：即使在 σ_slope → 0 的极限下，太阳形状本身决定了 S95 ≈ 18 m² 的下界。σ_slope = 0.5 mrad 时附加 ~8 m²，σ_slope = 1.0 mrad 时附加 ~30 m²。这个分解与实测数据（21.1 → 27.9 → 50.0）高度吻合。
