## 判读

### H1（修复后重力惩罚显著 >1）：**成立，但量级只有卷积预测的一半**

- 实测惩罚 1.001–1.539×，逐镜趋势与 H3 卷积模型高度一致
  （Pearson r=0.913，Spearman ρ=0.922：South > East/West > North，近距离 > 远距离，
  North 远镜几乎无惩罚 1.001–1.012 ✓）。
- 但实测/预测均值仅 **0.634**——卷积模型 `S95∝σ_tot²` 系统性高估 ~1.6×。
  含义：S95 面积对额外斜率方差的响应是**亚二次**的（尾部权重使 S95 增长慢于 σ²）。
  H3 需修正为 `S95比值 ≈ (σ_tot/σ_base)^α，α<2`——趋势可预测、标定需一阶修正，
  这本身就是"可预测光学"的一个定量结果。
- 物理量级检验：South_150m 的 +28 m² 惩罚（52→80）是**真实、不可忽略**的重力光学代价；
  North 远镜的重力代价可忽略——**重力问题本质上是近场 South/East/West 镜的问题**。

### Δ_envelope（闭式均值场补偿的收益）：**近场显著、远场≈0，H2 成立**

- h\* init 在惩罚最大的镜面上收益最大：South_150m +5.10、South_300m +3.40、East_150m +3.17 m²
  （消去惩罚的 18%、14%、12%）。
- ≥900m 与 North 各镜 Δenv≈0 甚至略负（−0.58…+1.39）：均值场本身占比小，
  补偿在 S95 非线性下略有反噬（量级 <0.2%，可视为噪声级）。
- 补偿后比值仍 1.006–1.440 > 1：**结构性地板存在**（θ 变化 + 支撑间凹陷），
  与 Phase 0 §3–§4 的预测定性一致——闭式补偿只能吃掉惩罚的一小部分（~10–18%），
  剩余部分必须靠正则化微调（Phase 3）逼近，且存在 B_reachable > B\* 的硬地板。
