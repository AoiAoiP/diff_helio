## 1. 传统 σ_slope 的物理组成

在传统定日镜光追仿真中（如 SolTrace、Tonatiuh、以及 ARCAim 的 planar 模式），σ_slope 是一个**集总参数（lumped parameter）**，它将所有导致真实表面偏离理想光滑表面的因素打包为一个高斯标准差。学术界和工业界常用的 σ_slope = 1.0 mrad 包含了以下物理来源：

| 误差来源 | 空间尺度 | 典型贡献 (mrad) | 能否被显式面型捕获？ |
|---|---|---|---|
| **重力垂曲** (gravity sag) | 全板面 (0.1-10m) | 0.3-0.5 | ✅ 是 — 20-bin NLGEOM FEA |
| **螺栓调节变形** | 全板面 (0.5-5m) | 可变 (0-40mm stroke) | ✅ 是 — TPS 影响函数 |
| **制造波纹度** (manufacturing waviness) | 中等 (0.1-2m) | 0.2-0.4 | ❌ 部分 — 大于网格间距的特征可捕获 |
| **TPS 代理模型误差** | 中等 (0.4-2m) | 0.3-0.5 (有效值) | ❌ 否 — 系统性偏差 |
| **亚网格微起伏** (sub-grid micro-waviness) | 细 (0.01-0.4m) | 0.2-0.5 | ❌ 否 — 低于 Nyquist 频率 |
| **镜面粗糙度** (specularity) | 微观 (μm-mm) | 0.05-0.2 | ❌ 否 — 光学尺度的随机性 |
| **热变形** (thermal distortion) | 全板面 | 0-0.3 | ❌ 否 — 未建模 |
| **螺栓执行误差** (actuation tolerance) | 点 | 0.02-0.05 | ❌ 否 — 机械容差 |

**关键洞察**：在传统仿真中占 σ_slope 约 30-50% 的重力垂曲分量，现在已经被我们的 20-bin NLGEOM FEA 模型显式求解。这是调低 σ_slope 的主要理由。

## 2. 本项目显式模型的 Nyquist 限制

TPS 代理模型定义在 **32×32 网格**（间距 ~400mm × ~300mm）上。此离散化带来的 Nyquist 频率限制：

| 参数 | 值 |
|---|---|
| 板面尺寸 | 12.84 × 9.45 m |
| 网格间距 Δx | 12.84 / 31 ≈ 414 mm |
| 网格间距 Δz | 9.45 / 31 ≈ 305 mm |
| Nyquist 频率 (X) | 1 / (2×0.414) ≈ 1.2 cycles/m |
| Nyquist 频率 (Z) | 1 / (2×0.305) ≈ 1.6 cycles/m |
| 可分辨最小波长 λ_min | ~830 mm (X), ~610 mm (Z) |

**任何空间频率高于 Nyquist 限的表面特征都无法被 32×32 网格表达**，即使使用解析的 TPS 核函数（RBF 可以在任意点求值，但模型的输入——35 个螺栓系数——只能编码 35 个空间自由度）。

### 2.1 亚网格斜率误差估算

即使在最佳 TPS 拟合下，亚网格波纹仍会产生局部斜率偏差。对于一个振幅 A、波长 λ 的正弦波纹：

```
RMS_slope = (2π × A) / (√2 × λ)
```

| λ (mm) | A = 0.05mm | A = 0.10mm | A = 0.20mm |
|---|---|---|---|
| 800 (Nyquist 限) | 0.28 mrad | 0.56 mrad | 1.11 mrad |
| 400 | 0.56 mrad | 1.11 mrad | 2.22 mrad |
| 200 | 1.11 mrad | 2.22 mrad | 4.44 mrad |
| 100 | 2.22 mrad | 4.44 mrad | 8.88 mrad |

对于 4mm 厚的浮法玻璃，典型的制造波纹度振幅在 0.05-0.15mm 范围。λ < 400mm 的亚网格波纹会产生 0.5-3 mrad 量级的局部斜率误差。这些是真正的随机误差（与具体制造批次相关），无法被任何宏观模型预测，应当保留在 σ_slope 中。

## 3. TPS 代理模型误差的有效斜率贡献

我们已知 TPS proxy vs FEA 的验证结果：

| 角度 | RMS (mm) | R² | shape_corr |
|---|---|---|---|
| 29.5° (NLGEOM-ON) | 1.94 | 0.955 | 0.980 |
| 58.5° (NLGEOM-ON) | 2.04 | 0.952 | 0.980 |

### 3.1 TPS 误差是系统性的，不是随机的

TPS 模型误差 w_err(x,z) = w_FEA(x,z) − w_TPS(x,z) 具有空间相关性，**不是白噪声**。这很重要——因为：

- **光线追迹层面**：系统性误差在相邻光线之间是相关的，其光斑扩散效应不同于白噪声的高斯模糊
- **优化层面**：系统性误差造成的光斑偏差是确定的（对给定螺栓配置），优化器不会"学到"补偿它

### 3.2 有效随机斜率误差

将 TPS 误差转换为等效随机斜率误差需要估计其相关长度 L_corr。从 R²=0.955 可推算：

```
Var[w_err] = (1 − R²) × Var[w_FEA]
           = 0.045 × Var[w_FEA]
```

若 FEA 总变形 PV ≈ 10mm，RMS ≈ 3mm，则：
```
RMS(w_err) ≈ √0.045 × 3mm ≈ 0.64 mm
```

假设 TPS 误差的相关长度 L_corr ≈ 1m（与螺栓间距相当）：
```
σ_TPS_effective ≈ RMS(w_err) / L_corr ≈ 0.64 mrad
```

但这是**保守上界**——由于误差的空间相关性，其对远场光斑的扩散效应远小于同幅度的白噪声。对于接收器距离 ~150-1200m 的远场，取一半作为等效白噪声：**σ_TPS_effective ≈ 0.3 mrad**。

## 4. 推荐的分层 σ_slope 方案

### 推荐值：σ_residual = 0.5 mrad

```
σ_residual² = σ_specularity² + σ_subgrid² + α² × σ_TPS²
            = 0.15² + 0.30² + 0.5² × 0.64² / 4
            ≈ 0.02 + 0.09 + 0.03
            ≈ 0.14
σ_residual ≈ 0.37 mrad

→ 工程取证取整：σ_residual = 0.5 mrad
```

### 各分量的物理依据

| 分量 | 推荐值 | 依据 |
|---|---|---|
| σ_specularity | **0.15 mrad** | 4mm 浮法玻璃标准镜面反射率 (ISO 9050) |
| σ_subgrid | **0.30 mrad** | 亚网格波纹度，Δx=400mm, A≈0.1mm（制造公差） |
| σ_TPS (等效) | **0.20 mrad** | TPS vs FEA R²=0.96 的残余，经远场投影衰减 |
| **RSS 合计** | **~0.40 mrad** | → **取证取整为 0.5 mrad** |

### 为什么不是更小的值（如 0.2 mrad）？

1. **制造不确定性**：不同批次玻璃的波纹度差异可达 2×
2. **热变形未建模**：低仰角 + 高 DNI 时热梯度可达 5-10°C，附加斜率误差 0.2-0.5 mrad
3. **螺栓执行容差**：机械调节精度 ~0.02mm → 局部斜率误差 ~0.05 mrad（小但非零）
4. **保守原则**：在缺乏实测数据时，宁可略微高估残余误差，保证优化结果的物理可实现性

### 为什么不是更大的值（如 1.0 mrad）？

1. **重力垂曲已被显式建模**：这是传统 1.0 mrad 中的最大分量 (~0.4 mrad)
2. **螺栓变形已被显式建模**：35 自由度 TPS 模型捕获了主要的低频面型变化
3. **过大的 σ 会使优化器"近视"**：无法区分精细螺栓调节的效果，导致优化结果过于保守

## 5. σ_slope 对优化行为的定量影响

### 5.1 有效光束宽度的贡献

反射光束的角扩散来自两个主要卷积：

| 来源 | 宽度 (rad) | 备注 |
|---|---|---|
| 太阳形状 (Buie CSR=0.01) | σ_θ ≈ 2.2 mrad | 由 sunshape 模型决定 |
| 斜率误差 (反射加倍) | σ_beam = 2 × σ_slope | 反射定律：δθ_out = 2 × δθ_surface |

有效总光束宽度（RSS 近似）：
```
σ_total = √(σ_sun² + (2·σ_slope)²)
```

| σ_slope | 2·σ_slope | σ_total (RSS) | 斜率误差占比 |
|---|---|---|---|
| **1.0 mrad (旧)** | 2.0 mrad | √(2.2² + 2.0²) = 2.97 mrad | **45%** |
| **0.5 mrad (推荐)** | 1.0 mrad | √(2.2² + 1.0²) = 2.42 mrad | **17%** |
| 0.2 mrad | 0.4 mrad | √(2.2² + 0.4²) = 2.24 mrad | 3% |

**关键转折点**：σ_slope = 1.0 → 0.5 mrad 时，斜率误差对总光束宽度的贡献从 45% 降至 17%。太阳形状成为绝对主导。这意味着**优化器将更激进地追求尖锐聚焦**——因为精细的螺栓调节现在可以"透过"更小的随机模糊看到收益。

### 5.2 灵敏度分析

用 S95 对螺栓高度的敏感性来理解：

```
∂(S95)/∂h_b ∝ 1 / σ_total
```

减小 σ_slope 会使梯度信噪比提升。在 σ_slope=1.0→0.5 时，σ_total 下降约 18%，梯度幅度增大约 22%。优化器将：

1. **更快收敛**（前 50 轮）
2. **更低的最终 S95**（因为可以"瞄准"更锐利的光斑）
3. **更大的最终螺栓行程**（max_stroke 可能增加 10-20%）

## 6. 实验验证结果（2026-07-22）

已对 North 300m 镜运行 5 组 σ_slope 对照实验（200 iter, lr=4e-4 constant）：

| σ (mrad) | Best S95 (m²) | Max Stroke (mm) | 耗时 (s) |
|---|---|---|---|
| **0.2** | **21.08** | 34.97 | 403 |
| **0.5** | **27.90** | 35.52 | 404 |
| **0.8** | **39.41** | 35.12 | 569 |
| **1.0** | **50.02** | 35.68 | 1050 |
| **1.5** | **86.44** | 36.38 | 812 |

**核心发现**：
- 螺栓行程几乎不变（35-36mm），说明 tanh 界（40mm）是所有情况下的 binding 约束
- S95 与 σ_slope 近似二次关系（R²≈0.997），符合 σ_total² ∝ σ_sun² + 4σ_slope² 理论
- 更小的 σ 收敛更快（梯度信噪比更高）
- 螺栓配置 pairwise RMS 差异仅 0.3-0.7mm——σ_slope 控制的是 S95 的"计量单位"，而非优化方向

详见 `analysis/sigma_slope_experiment_report.md`。

## 7. 实施建议

### 7.1 推荐 σ_slope

| 场景 | σ_slope | 理由 |
|---|---|---|
| 日常优化（推荐） | **0.5 mrad** | 物理标定值，平衡准确性与收敛速度 |
| 与传统结果对比 | 1.0 mrad | 匹配历史基线 |
| FEA 验证/生产 | 0.5 mrad | 当 TPS 代理被 POD-ROM 替代后，可降至 0.3 mrad |
| 应力测试 | 0.2 mrad | 验证优化器在极端清晰度下的行为 |

### 7.2 更精细的方案（远期）

如果希望物理上更精确地区分随机误差和系统性误差：

1. **保留 σ_slope** 仅用于真正的微观随机误差（specularity + sub-grid waviness）
2. **将 TPS 模型误差**作为后处理验证步骤，而非内嵌到光追中
3. **对 TPS 模型误差进行空间相关性建模**（如使用 Gaussian Process 或 Kriging 插值残差），在光追中施加空间相关的扰动场而非逐光线独立的白噪声

## 8. 结论

| 问题 | 结论 |
|---|---|
| 是否应删除 σ_slope？ | **否**。亚网格误差（波纹度+镜面粗糙度）仍需统计建模 |
| 是否应调小 σ_slope？ | **是**。从 1.0 mrad 降至 **0.5 mrad** |
| 调小的物理依据？ | 重力垂曲+螺栓变形已被显式建模，这两项占传统 σ 的 40-50% |
| σ=0.5 包含什么？ | 镜面粗糙度(0.15) + 亚网格波纹度(0.30) + TPS模型残余(0.20) RSS |
| 对优化结果的影响？ | S95 改善（在不同 σ 下不可直接比较），收敛更快，螺栓配置几乎不变 |
| 2026-07-22 实验确认 | σ_slope 控制的是 S95 的"计量单位"而非优化方向；所有 σ 值下螺栓配置高度一致 |
| 多久验证一次？ | 建议每次更换数据源（新 gravity/influence 数据）时重新校准 |

**核心思想**：σ_slope 在传统仿真中是"我们不知道表面长什么样"的代理。现在我们知道得更多了——知道重力怎么弯、螺栓怎么调——σ_slope 就应该只代表"我们仍然不知道的那部分"。

## 附录 A：代码路径追踪

斜率误差在本项目中的使用路径：

```
config.h:34
  float slopeError = 0.001f;  // ← 唯一配置点
       │
       ▼
pipeline.cpp:1295
  helio[4] = m_cfg.slopeError;  // → UBO HeliostatParams.slopeError
       │
       ▼
common.slang:250
  getHeliostatSlopeError() → heliostat.slopeError  // UBO 读取
       │
       ├─ forward.slang:107, 161-164
       │    nor1 = perturbNormal(surfNrm, slopeErr, g0, g1);  // 入射面法向扰动
       │    nor2 = perturbNormal(surfNrm, slopeErr, g2, g3);  // 出射面法向扰动
       │
       └─ bolt_backward.slang:208-210
            pp1 = normalize(g0*sigma, 1, g1*sigma);  // 反向传播重放相同扰动
            pp2 = normalize(g2*sigma, 1, g3*sigma);
```

**扰动幅度**：每次扰动是 `(rx×σ, 1.0, rz×σ)` 归一化 → 等效角偏转 ≈ σ × √(rx² + rz²) / 1.0 ≈ σ × Rayleigh(σ=1) ≈ 1.25 σ RMS。对 σ=1 mrad，每次扰动产生 ~1.25 mrad RMS 的局部法向偏转。经折射，出射光线的等效偏转约为 `2 × 1.25 mrad / 1.523 ≈ 1.6 mrad`（除以折射率因为弯曲在玻璃内部减小）。
